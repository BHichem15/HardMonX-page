System Overview

HardMonX is a comprehensive system monitoring tool developed as a CS50x final project by Bourenane Chàabane. It provides real-time insights into your computer's performance metrics with a clean, intuitive interface.

CPU Usage

Monitor processor utilization and temperature in real-time across all cores

RAM Usage

Track memory consumption, swap usage, and available resources

Disk Storage

View disk space usage, read/write speeds, and performance metrics

Network Stats

Measure upload/download speeds and monitor network connections

Key Features

HardMonX combines powerful monitoring capabilities with an elegant user interface

Real-time Monitoring

Get live updates of all system metrics with minimal performance impact and customizable refresh rates.

Auto-refresh

Metrics update automatically every 3 seconds (configurable) for the latest system information.

Cross-platform

Works seamlessly on Windows, macOS, and Linux systems with a consistent experience.

Lightweight

Minimal resource usage (under 50MB RAM) while providing comprehensive monitoring.

Simple GUI

Built with Tkinter for an intuitive user experience with dark/light theme support.

Open Source

Customizable Python code that you can modify and extend for your specific needs.

Installation Guide

Get started with HardMonX in just a few simple steps

1. Install Dependencies

# Install required Python packages pip install psutil speedtest-cli matplotlib tkinter

2. Run the Application

# Clone the repository git clone https://github.com/bhichem15/HardMonX.git # Navigate to project directory cd HardMonX # Run the application python main.py

3. Project Structure

HardMonX/ │ ├── backend/ │ ├── __init__.py │ ├── app.py # Backend server │ ├── cpu_monitor.py # CPU Monitoring Module │ ├── memory_monitor.py # Memory Monitoring Module │ ├── disk_monitor.py # Disk Monitoring Module │ ├── network_monitor.py # Network Monitoring Module │ └── requirements.txt # Required dependencies │ ├── frontend/ │ ├── __init__.py │ ├── ui.py # GUI implementation │ └── ui_styles.py # UI styling and theming │ ├── main.py # Entry point to start the application │ ├── data.json # Performance history storage │ ├── .gitignore # Files to exclude from Git │ └── README.md # Project documentation

4. Build Standalone Executable

# Install PyInstaller pip install pyinstaller # Build executable (Windows) pyinstaller --onefile --windowed --icon=icon.ico main.py # Build executable (macOS/Linux) pyinstaller --onefile main.py
